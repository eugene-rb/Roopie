# 2026-07-29: タブグループのデザインを「グループそのもの」へ移し、チップと2段目をつなげた

## 決定事項とWhy

ユーザー依頼「タブの見た目設定のうち、タブグループのデザインはタブグループの中身(下段)ではなく、グループそのもの(上段)へ適用して。また、下段は背景に色を付けることを右クリックから以外はすべて上段と同じデザインにして。グループと中身の関連を感じられるようにタブグループそのものと下段の背景をつなげるデザインにして」。

**① エフェクトの描画先を中身のタブ → チップへ**

- `applyTabEffects()` からグループ系統を削除。タブに重なるのは「アクティブ」「メディア再生中」の2系統だけになった(グループに入っていても1段目のタブと同じ見た目)。
- 新設した `applyGroupChipEffects(chipEl)` が `createGroupChip()` の中で `.tab-fx[data-kind=group]` を1枚積む。重ね掛けの共通処理(`--fx-delay`・`.fx-nyan` の印・append)は `attachTabFx(el, layers)` に切り出してタブと共用。
- 色の既定は `var(--group-color, var(--group-grey))`。チップには `data-color` が付いていて `--group-color` が入るので、タブ側でやっていた `var(--group-${group.color})` の組み立てが要らなくなった。
- `.tab-group-chip` に `position: relative; isolation: isolate` を追加(`.tab` と同じ。無いと `z-index:-1` のエフェクトがタブバーの背景の裏に沈む)。

**② 2段目は「地の色」以外を1段目に揃える**

- 高さ36px → 40px、余白 `0 8px` → `5px 8px`、`#group-new-tab-btn` 24px → 28px(`#new-tab-btn` と同じ)。
- 上端の境界線(`box-shadow: inset 0 1px 0`)は**削除**。チップから伸ばす橋をそこで切ってしまうため。
- `-webkit-app-region: drag` は付けない(1段目と違い、ここはタブのドロップ先)。
- 地の色は右クリックの「色」で決まる `--group-color` 由来のまま = 唯一の違い。

**③ チップと2段目をつなぐ「橋」**

- 2段目が出ているグループのチップに `.linked` を付ける(renderer が `showGroupRow && groupId === currentGroupId` で判定。縦タブでは2段目が無いので付かない)。
- `.linked` は下端の角丸を落とし、背景を2段目と同じ `--group-fill`(グループ色18% + `--bg`)にし、`::after`(`top:100%`・高さ `--group-bridge`=5px)でタブバーの下パディングを埋める。チップ→橋→2段目が1枚の面になる。
- **`#tabs` は `overflow-y: hidden` だが、スクロールコンテナが中身を切るのはパディングボックス**。`.chrome-body:not(.vertical-tabs) #tabs { padding-bottom: 5px; margin-bottom: -5px }` を足して、はみ出した橋が切られない逃げ場を作った(負のマージンでタブバーの下パディングに重ねるのでタブの位置は動かない)。橋は絶対配置なので `#tabs` の高さにも効かない。
- JSで座標を測って橋を置く案もあったが、CSSだけなら**タブバーを横スクロールしても橋がチップに付いて動く**のでこちらにした。
- 下寄せのエフェクト(`underline` / `gradient-underline` / `bars`)は継ぎ目にちょうど線を引いてしまうので、`.linked .tab-fx { bottom: var(--group-bridge) }` で持ち上げる(`.tab.split .tab-fx { bottom: 2px }` と同じ考え方)。`.active` の下線(`inset 0 -2px 0`)も `.linked` では消す。

**踏んだ罠**

- **`--group-fill` を `:root` に置くと常にグレーになる**。カスタムプロパティの中の `var()` は「宣言した要素」で先に展開されるため、`--group-color` を持たない `:root` で `var(--group-color, var(--group-grey))` がグレーに固まり、そのまま継承される。`--group-color` が入る要素(`.tab-group-chip` と `#group-row`)の側で宣言する。
- **チップに `container-type: inline-size` を付けるとチップが20pxまで潰れる**。インラインサイズの封じ込めは幅の計算で中身を見なくなるため。タブは `width: 200px` 固定なので平気だったが、チップは中身で幅が決まる。よってチップのニャンキャットは細くなったら猫を消すコンテナクエリを持たず、**猫のぶん(38px)だけチップが広がる**形にした。

**設定画面**

- 「タブグループのタブ」→「タブグループ」。説明も「1段目のグループそのものに出る/中のタブは普通のタブと同じ」に書き換え。
- プレビューも本物と同じ組み立てで**チップ**(`.tab-group-chip.active[data-color=blue]` + ドット/名前/件数)を出す。
