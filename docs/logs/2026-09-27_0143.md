# 2026-09-27: hitomi.la 専用の広告ブロック

## 決定事項と理由

- 既存の Ghostery エンジンに hitomi.la 限定のネットワークルールを追加。別の `webRequest` リスナを登録すると既存の遮断処理を上書きするため。
- hitomi.la のページ用 CDN (`gold-usergeneratedcontent.net`) は許可し、その他の外部スクリプトを遮断する。
- 汎用コスメティックフィルタは YouTube の表示と衝突するため、hitomi.la の広告枠と `window.open` だけを専用 preload で処理する。広告ブロック設定の変更は開いているページにも反映する。

## 検証

- Ghostery エンジンで広告配信元が遮断、ページ用 CDN と他サイトが許可されることを確認。
- 実際の hitomi.la を Electron で開き、広告枠が `display: none`、ポップアップが抑止され、設定オフで両方が元に戻ることを確認。
- `scripts/test-trackers-panel.js`、`node --check`、`git diff --check` が成功。
