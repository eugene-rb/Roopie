# 2026-07-28: タブの閉じるボタンをホバー時のみに + 音声再生中タブのエフェクト(15種・設定で選択)

## 決定事項とWhy

ユーザー依頼2件「タブの×ボタンはホバー時のみ表示、それ以外の時はその部分にもタイトルを表示して」「音声再生中のタブはエフェクトを付けてわかりやすくして。そのエフェクトも設定から単色やグラデーション、アニメーションなど幅広い選択肢から変えられるように」。追加でニャンキャットのCSS実装を渡され「このコードを参考に縮小して猫全体が入るように追加して」。

- 閉じるボタン(`tailwind.css`)
  - `visibility: hidden` → **`display: none`** に変更。visibilityだと場所を取り続けるのでタイトルが伸びない
  - 表示条件から `.tab.active` を外し、**ホバー中のタブだけ**に(依頼どおり。アクティブでも非ホバーなら出さない)
  - 実測: 非ホバー時のタイトル幅 162px → ホバー時 138px(24px = ボタン18px + gap6px ぶん伸びる)

- 音声再生中のエフェクト
  - 設定は `DEFAULT_SETTINGS`(プロファイル別)に `audioTabEffect` / `audioTabEffectColor` / `audioTabEffectColor2` を追加。既定は `breathe`、色は空文字=アクセント色に追従
  - `ipc.js` の `settings:set` に検証分岐を追加(`AUDIO_TAB_EFFECTS` のホワイトリスト、色は `#rrggbb` か空文字のみ)。既定の else 節は無検証で通してしまうため
  - `renderer.js` … `tab.isAudible && !tab.isMuted` で `.audible` を付け、種類は `body[data-audio-effect]`、色は `--audio-fx-1/2` をルートに置く
  - CSS の起点を **`[data-audio-effect] .tab.audible`** にしてある(bodyでも設定画面のプレビュー用ラッパーdivでも同じルールが効く)
  - 描画は `.tab::after` に載せる。`.tab.split` が `inset` の box-shadow を使っており、**box-shadow は重ねられない**ので `.tab` 本体には書けない
  - `.tab` に `position: relative` + **`isolation: isolate`** を追加し、`::after` を `z-index: -1` に。重なり文脈ができるので「タブの背景より上・文字やアイコンより下」に入る
  - 効果は全15種: なし / 単色4(塗り・枠線・下線・内側の発光)/ グラデーション3(塗り・下線・枠線)/ アニメーション6(明滅・呼吸する発光・グラデーションが流れる・光が横切る・イコライザー・虹色に巡回)/ ドット絵1(ニャンキャット)
  - 装飾は**タブの内側で完結**させる(縦タブでは `#tabs` が `overflow-x: hidden` なので外へ広がる影は見切れる)
  - **`--audio-fx-1/2` は `:root` にも既定値を置く**。JSが入れる前提で書いていたが、未定義だと `color-mix()` ごと無効になり**15種中13種が丸ごと消える**(全種を1枚に並べて目視して発覚。「背景か影が付いているか」の機械判定では真っ白に通る)
  - `.tab.split` の下線(inset box-shadow)は「背景+影」の段階で描かれ、`z-index:-1` の `::after` は**その後**に描かれるので全面塗りのエフェクトが線を覆う。`.tab.split.audible::after { bottom: 2px }` で線のぶんだけ空ける

- アニメーションが毎秒巻き戻る問題(実装前に実測して対処)
  - `probeMedia` が**再生中は1秒間隔**で走り → `refreshMedia` → `media:state` → `renderTabs()` が `tabsEl.textContent = ''` で全タブを作り直す。素直に `@keyframes` を書くと毎秒0秒目に戻ってガタつく
  - 対策① `renderer.js` の `onMediaState` で `tabId:playing` だけの署名を作り、**変わっていなければ再描画しない**(再生位置しか動いていない更新を捨てる)
  - 対策② タブ生成時に共通の時計から `--fx-delay: -(performance.now()/1000 % 60)s` を入れ、全アニメーションが `animation-delay: var(--fx-delay)` を読む。**各アニメーションの長さは60秒を割り切れる値**(1.5/2/2.5/3/4/6/0.5/1s)にしてあるので、作り直しても位相が続く
  - 検証は `animation.currentTime` ではなく **`getComputedTiming().progress`** で見る(currentTimeは負のdelayを含まないので巻き戻りを検出できない)

- ニャンキャット(渡されたCSSからの移植)
  - 元CSSは `linear-gradient` を100枚以上重ねてドット絵にする実装。**1マス=1px(元は10px)まで縮めると重ね合わせは潰れて読めない**ため、同じドットデータから**6コマのスプライトシート(SVG)を焼き直す**方式に変更
  - `scripts/gen-nyan-sprite.js` … 元CSSのカラーストップ(`100%/21*2` 等)をマス目に読み替えたドットデータを持ち、`@keyframes` を step-end で読んだコマ別オフセット(catCycle/headCycle/feetCycle/feetSpriteCycle/tailCycle/tailSpriteCycle)で合成して SVG を吐く。出力は `src/renderer/nyan-sprite.css`(`--nyan-cat` 15.5KB / `--nyan-rainbow` 0.6KB の data URI)。tailwind.css から `@import` してビルド時に app.css へ入る
  - 猫は **34×21px**(しっぽ-7〜頭+27で原点を+7ずらした箱)。30pxのタブに丸ごと収まる
  - 虹は元CSSの重ね合わせを展開して **16×19px の1タイル**にし `repeat-x`。階段状の縁もそのまま
  - 虹(`::before`)の上に猫(`::after`)を重ねる。**どちらも z-index:-1 なので負のレイヤー内では文書順**=虹→猫の順に描かれる
  - `::before` は `animation` ショートハンドを使うので **`animation-delay` は必ずその後**に書く(ショートハンドがdelayを0に戻す)
  - 猫の居場所は `.title { margin-right: 38px }` + ボタン類の `position: relative; right: 38px` で空ける。**`.tab` の padding では駄目**=要素は自分自身のコンテナクエリに反応できず、細いタブで猫を消す逃げ道が無くなるため(padding方式では61pxのタブでタイトル幅が0になるのを実測)。**`> *:last-child` への margin も駄目**=最後の子は非表示の閉じるボタンで、見えているボタンが動かない。タイトルは `flex: 1` で余りを吸うのでタイトルへの margin だけでもボタンは動かない
  - `container-type: inline-size` + `@container (width < 150px)` で、**細いタブでは猫を出さず虹だけ**にする(虹は右端まで伸ばし opacity 0.45 まで落とす=極彩色でfaviconが沈むため)。`@container` ブロックは打ち消す対象より**後**に置く(`::before { right: 31px }` が後にあると効かない)
  - 虹の上でもタイトルが読めるよう `.title` に text-shadow、虹は opacity 0.8
  - 元CSSからの意図的な変更: 虹の動きは 0↔-9px の往復ではなく `steps(8)` で左へ流す(タブでは流れて見えるほうが自然)。色設定(`--audio-fx-*`)は使わず虹色固定
