# 2026-07-29: タブバーまわり4件(ニャンキャットの縁取り・ボタン配置 / ✕連打中の幅固定 / 閉じた後の行き先設定)

## 決定事項とWhy

ユーザー依頼4件。

**① ニャンキャット時の縁取り**(「nyancat時に文字や音量のアイコンなどが読みやすいように黒い縁取りをして」)

- 対象は `[data-audio-effect='nyan'] .tab.audible` の中だけ(他のエフェクトには広げない)。
- 文字(`.title` / `.favicon-letter` / `.close-btn`)は**8方向のぼかし無し `text-shadow`**で輪郭を作り、色は `#fff`。
  - **`-webkit-text-stroke` + `paint-order` は不採用**: ストロークはグリフの内側にも半分入るため、12pxの漢字では内側の隙間(「新」「設」など)が1px幅しかなく黒く潰れて逆に読めなくなる。
  - 元からあった `text-shadow: 0 1px 2px rgba(0,0,0,.95), 0 0 4px rgba(0,0,0,.85)`(ぼかし影)は置き換え。極彩色の上ではぼかしが溶けて効いていなかった。
- アイコン(`.favicon` / `.play-btn svg` / `.audio-btn svg`)は文字ではないので **`drop-shadow()` を4方向ぶん連鎖**。連鎖すると前段の影ごと膨らむため、斜めも埋まって全周が縁取られる。
  - **ボタン要素ではなく中身のSVGに掛ける**: `.audio-btn`/`.play-btn` はホバー時に `rgba(255,255,255,.15)` の背景が付くので、要素に掛けるとその角丸まで縁取られる。
  - 線のアイコンは viewBox 24 を 12px で描くため実寸1pxしかなく、黒い縁取りだけだと潰れて見える。`color: #fff` にして芯を白く残す。ミュート中(`.audio-btn.muted`)はアクセント色に意味があるので `:not(.muted)` で除外。

**② 再生/ミュートを左寄せ、✕は本来の位置**(「再生ボタンやミュートボタンを左揃えにして。×は猫を消して本来の場所に表示して」)

- 従来は猫(右端34px)を避けるため `.play-btn`/`.audio-btn`/`.close-btn` を `position:relative; right:38px` で3つとも左へずらしていた。これをやめ、**flexの `order`** で並べ替え(`.favicon`/`.favicon-letter`/`.spinner` = `-2`、`.play-btn`/`.audio-btn` = `-1`)。DOMの生成順は変えない。
- ✕はホバー中だけ `display:flex` になり、猫と同じ右端に出る。**`.tab.audible:hover::after { content: none }`** で猫を消し、空いた場所はタイトル(`margin-right:0`)と虹(`right:0`)を伸ばして埋める。
- `@container (width < 150px)`(細いタブ)のブロックからはボタンの `right:0` 打ち消しを削除(ずらさなくなったため不要)。このブロックは打ち消し対象より後に置く決まりなので位置はそのまま。

**③ ✕の連打中はタブ幅を固定**(「×ボタンでタブを削除するときに、連続してたくさん削除できるように、削除が1秒間行われないのを待ってからタブの幅を広げるようにして」)

- タブが縮んでいる状態(overflow手前)で1枚閉じると残りが少しずつ広がり、次の✕がカーソルの下から逃げる。
- `renderer.js` に `lockTabWidths(tabEl)`: 閉じた瞬間のタブ幅を `#tabs` の `--tab-lock-w` に入れ `width-locked` クラスを付ける。`clearTimeout`+`setTimeout(1000)` で**最後に閉じてから1秒**経ったら外す。
- CSSは `.chrome-body:not(.vertical-tabs) #tabs.width-locked .tab { width: var(--tab-lock-w) }` の1行だけ。`.tab` は `flex-grow: 0` なので**幅(=flex-basis)を上書きするだけで広がらなくなる**(`min-width` では上限を止められない)。`flex-shrink` は生きたままなので、固定中に新しいタブが増えても `min-width:140px` までは縮む。
- クラスは**タブ要素ではなく `#tabs` に付ける**。`renderTabs()` はタブを毎回作り直すが `#tabs` 自体は残るため、固定が再描画で消えない。
- 縦タブは1枚閉じても幅が変わらないので対象外。JS側で `isVerticalTabs()` なら早期return、CSS側も `:not(.vertical-tabs)` で限定(`.chrome-body.vertical-tabs .tab{width:100%}` より `#tabs...` の方が詳細度が高く、レイアウトを切り替えた瞬間に固定が残ると幅指定を奪ってしまうため)。

**④ 閉じた/移した後に直前のタブへ戻る設定**(「現在のアクティブタブを、削除したりドラッグアンドドロップで移動したりした後、各場合においてそれより一つ前にアクティブだったタブに移動するように設定で選べるようにして」)

- `TabManager` に `recentTabIds`(先頭=直前にアクティブだったタブ。今のアクティブは含まない)を追加。`switchTab()` で旧アクティブを先頭に積み(重複は排除、上限100)、これから使うIDは降ろす。`closeTab`/`releaseTab` では取り除いたタブのIDを履歴からも消す。
- 行き先の決定を `nextActiveAfterRemoval(index)` に集約し、`closeTab`(閉じる)と `releaseTab`(D&Dで別ウィンドウへ移す/切り離す)の両方から呼ぶ。設定OFF(既定)は従来どおり `tabs[Math.min(index, length-1)]`(=右隣、末尾なら左隣)。
- 設定 `activatePreviousTabOnClose`(プロファイル別、既定 false)。`browser.applyActivatePreviousTabFor()` で開いている全ウィンドウへ即時反映(`ipc.js` の `settings:set` から呼ぶ)。設定画面「タブ」セクションにトグルを追加。
- 分割中に主ペインを閉じたときの「相方のペインを昇格」は従来どおり優先(設定より前で分岐)。

**検証**: 新規 `scripts/test-tab-ui.js`(12項目)。閉じた後の行き先4パターン(OFF=同じ位置 / ON=直前 / ON=直前が既に閉じていたらさらに前 / ON=`releaseTab` でも同じ)、実クリックでの✕→幅が変わらない→1秒後に広がる、ニャンキャットの通常/ホバーの拡大スクショ。既存 `scripts/test-tab-audio-effect.js` はボタンのずらし方が変わったので2項目を `order` の確認に差し替え(全項目OK)。`test-window-tabs.js` / `test-tab-detach.js` / `test-tab-move-live.js` もリグレッションなし。

**ハーネスの注意(今回わかったこと)**:
- `sendInputEvent` の `mouseMove` だけでは `:hover` が乗らない。**`mouseEnter` → `mouseMove` の順**で送ると入る(ホバーでしか出ない✕を実クリックするのに必要)。
- `capturePage()` は `window.show()` + `focus()` の後でないと `UnknownVizError` で落ちる。
- `capturePage(rect)` + `image.resize({ width: w*5, quality:'best' })` で**一部だけ拡大したスクショ**が撮れる。1px単位の縁取りの目視はこれでないと判断できない。
- タブバーのレンダラーはクラシックスクリプトなので、`executeJavaScript` から `tabState` / `mediaList` / `renderTabs()` に直接触れる。音を鳴らすタブを用意しなくても「音声再生中の見た目」を作れる。
