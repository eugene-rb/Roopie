# 2026-07-29: イントロ(初回起動)を今の機能に合わせて更新

## 決定事項とWhy

ユーザー依頼「イントロ画面を更新して」。

- **機能カード**を今の Roopie に合わせ替えた(6枚): プロファイル / 広告ブロックとトラッキング分析 / **ページの翻訳(新)** / サイドパネル(タイマーを追記) / スタート画面 / **自分好みの見た目(新)**。マウスジェスチャーと画面分割は最後のステップの文章へ移した(カードを8枚にすると縦にあふれてボタンに重なるため。実測して6枚に戻した)。
- 「見た目を選ぶ」に**ウィンドウの明るさ**(システムに合わせる/ダーク/ライト)を追加。`api.setTheme({ windowMode })` なので選んだ瞬間にブラウザのUIが切り替わる。
- 「検索とプライバシー」に**翻訳の提案**(提案する/しない)を追加。翻訳先は日本語のままで、変更は設定画面に任せる(イントロを長くしないため)。
- 最後のステップの案内に `Ctrl+Shift+Y`(ページの翻訳)とタブの右クリック(画面分割・グループ化)を追記。
- 操作ボタンは**あふれたステップだけ**下端に貼り付ける(`.ob-actions.sticky` を welcome.js が付け外しする)。常に付けると、短いステップでぼかしの帯だけが宙に浮いて見えた(スクショで確認して直した)。ウィンドウを小さくしたときもボタンが押せることを検証に入れた。
- カードは詰め方を少し縮めた(gap 14→12 / padding 18→14・16 / アイコン 36→32)。3行になっても収まる余地を作るため。
- アイコンを3つ追加(`translate` / `palette` / `timer`。`onboarding-icons.js` はイントロと変更点で共通)。
- **変更点ページ(whatsnew)と release-notes.json は触っていない**。あちらは `VERSION_BASE` を上げるときに1件足す運用なので、イントロの更新では出し分けが変わらない。
- 検証: `npx electron scripts/test-onboarding.js [スクショdir]`(カードの枚数・追加した2枚の存在・アイコンが実体を持つこと・明るさと翻訳の即反映・収まるステップでは貼り付けない/小さいウィンドウでは貼り付けてボタンが見えることまで)。
