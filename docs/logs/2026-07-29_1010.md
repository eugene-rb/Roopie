# 2026-07-29: 翻訳機能(ページ翻訳・選択テキストの翻訳)をEdge準拠で追加

## 決定事項とWhy

ユーザー依頼「翻訳機能をつけて」「UIは基本的にedgeと同じにして」。

**① 訳文の取得(`src/main/translate.js`)**

- Google翻訳のWebエンドポイント `translate_a/t`(client=gtx、キー不要)へ**POST**。`q` を複数並べればまとめて訳せて、応答は `[["訳文","検出した言語"], ...]` の並びで返る(`sl=auto` のときだけ言語が付く)。実測で確認済み。
- 小分けは**本数(64)と文字数(1600)の両方**で切る。1本が4000文字を超えるテキストノードは諦めてそのまま返す。
- 訳文は原文→訳文のMapでキャッシュ(4000件、溢れたら古い順に捨てる)。ナビゲーションのラベルのような繰り返しを訳し直さない。シークレットが全部閉じたら捨てる(`browser.js` の closed)。
- **文字を含まない断片(数字・記号・空白だけ)は送らない**。応答は前後の空白を落として返すので、送ると「Price: 1,200」のような行の見た目が崩れるだけで得が無い。
- 「読めない言語か」の判定 `looksForeign(target, lang, sample)` は**通信しない**。`<html lang>` があればそれで決め、無ければ本文の見本を文字の系統(かな/漢字/ハングル/キリル/アラビア…)で見て、翻訳先の系統の文字が1割未満なら「別の言語」と見る(24文字未満は判定しない)。

**② DOMの差し替え(`src/preload/translate-preload.js`。分離ワールド)**

- 全ページのpreloadとして登録(`registerPagePreloads`)。指示が来るまで何もしない。media-guardと違いメインワールドへは入らない(DOMを触るだけなので分離ワールドで足りる)。
- `TreeWalker` でテキストノードを集め、**前後の空白を分けて中身だけ**訳し、`lead + 訳文 + trail` で書き戻す。原文はノードごとにMapで控え、「元の言語を表示」はその**書き戻し**(逆翻訳ではない)。
- 訳さないもの: SCRIPT/STYLE/TEXTAREA/INPUT/CODE/PRE/SVG/CANVAS/IFRAME等の中、contenteditable、`translate="no"`、`.notranslate`。
- 後から増えた文は `MutationObserver` で拾う(700msまとめ)。**書き込みの間は observer を外す**(disconnectは溜まった通知も捨てるので、自分の書き込みで走査が走らない=無限ループしない)。ページ側が訳文を書き戻してくる場合の綱引きは、同じノードを6回訳したら諦めることで止める。
- **最初の翻訳が途中で失敗したら、その回で書いた分を戻してから error を報告する**(中途半端に訳された画面を残さない)。訳し終えた後の追加分の失敗は、既に訳してあるページを壊さないのでそのまま。

**③ 取り回し(`src/main/page-translate.js`)**

- 状態は **`tab.translate`**(`state`/`source`/`target`)。タブのオブジェクトに載せるので、WebContentsViewごと別ウィンドウへ移しても一緒に運ばれる。`did-navigate` で捨てる(`tab-manager.js`。新しいリスナは足していない)。
- 状態は `tabs:state` の各タブに `translate` / `canTranslate` として乗せ、アドレスバーの翻訳アイコンがそれを見る。
- **訳文の要求は要求元タブのセッションで通信する**(`sender.session.fetch`)。既定セッションで投げるとTorを有効にしたプロファイルの文面がTorの外へ出る。
- 自動提案は読み込み直後の `translate:page-info`(preloadが `<html lang>` と本文の見本を送る)で決める。同じサイトでは起動中1度だけドロップダウンを自動で開く(シークレットは別枠)。
- 「常に翻訳する言語」に入っていれば尋ねずに訳す。「翻訳しない言語/サイト」は提案しない。
- **シークレットでは覚えない**(翻訳先の選択も除外リストも書かない。ドロップダウン側も「…」と「常に翻訳する」を出さない)。

**④ UI(Edgeの翻訳フライアウトに合わせた)**

- アドレスバーの中、ブックマークの星の左に翻訳アイコン。読めない言語のページ(提案中)と翻訳済みのページで出す。訳し終えると点灯、翻訳中はゆっくり点滅。**「元の言語を表示」で戻してもアイコンは残す**(そこからまた訳せる。消えるのは「このサイト/この言語は翻訳しない」を選んだときだけ)。
- ドロップダウンはオーバーレイ(`roopie://menu` の `#translate-popup`)。**アンカーの位置はツールバーが測って戻す**(サイトの権限と同じ経路。縦タブのずれは `chromeLeft` で補正)。中身は「翻訳元 → 翻訳先(選び直せる)」+「この言語のページを常に翻訳する」+「…」(このサイト/この言語は翻訳しない)。ボタンは 翻訳 / 今は実行しない、訳し終えたら 元の言語を表示 / 完了、失敗したら 再試行。
- 選択テキストの翻訳は同じ枠に原文+訳文を出す(右クリック→「選択したテキストを日本語に翻訳」)。選択位置に出すにはページ→ウィンドウ座標の変換が必要で得が無いため、アイコンにぶら下げる形にした。
- 右クリックメニュー(ページ)に「日本語に翻訳」/「元の言語を表示」、アプリメニュー「表示」に「ページを翻訳」(**Ctrl+Shift+Y**。keybindings.jsに追加したので設定画面から変更可)。
- 設定画面に「翻訳」セクション: 翻訳先の言語、提案のON/OFF、常に翻訳する言語/翻訳しない言語/翻訳しないサイトの一覧(削除のみ。追加はドロップダウンから)。

**⑤ 検証**: `npx electron scripts/test-translate.js [スクショdir]`(70件)。純関数の言語判定・通信回数・キャッシュ・小分けの上限、実ウィンドウでの提案→翻訳→書き戻し、後から増えた文、自分で書き換え続ける要素があっても要求が増えないこと、失敗時に原文が残ること、選択テキスト、権限の確認が来たら譲ること、除外リスト、シークレット、設定画面、縦タブのアンカー位置まで通しで見る。

**既知の制約**: 「この言語は翻訳しない」「常に翻訳する言語」の判定は `<html lang>` だけを見る。言語を宣言していないページでは、英語を除外していても提案が出る(実際の言語は最初の訳文の応答で初めて分かるため。読み込みごとに検出用の通信を足すのは割に合わないのでこうしている)。iframeの中は訳さない(`webContents.send` はメインフレームにしか届かない。必要になったら `framesInSubtree` + `frame.send` で広げる)。
