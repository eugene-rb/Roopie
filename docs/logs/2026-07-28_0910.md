# 2026-07-28: ページの中のフォルダをスマホのアプリフォルダ風に表示

## 決定事項とWhy

ユーザー依頼「ページの中に作ったサブフォルダとその中身はスタート画面でもフォルダとしてスマホのアプリフォルダのようなUIで表示して」(直前の対応で除外していた分)。

- レイアウトの保存形式は変えない。`widgets.js` の `sanitizeItem` は `shortcut`/`widget` しか通さないため、フォルダも既存の `{ type:'shortcut', refId }` として並び順を保存する(refIdがブックマークのフォルダIDになるだけ)
- `newtab.js`
  - `isGroup(item)`(= `type === 'folder'`)を追加。`loadShortcuts()` はページ直下のフォルダを除外せず、各フォルダの中身を `bookmarks:children` で並列に取って `folderContents`(フォルダID → 中のリンク)に持つ。**展開するのは1階層だけ**(フォルダの中のフォルダは持たない=無限に潜らない)
  - `groupItemEl()`: タイルに中身のアイコンを**2x2で最大4個**並べる(`tileIconContent` を再利用するのでemoji/画像/favicon/頭文字の扱いは通常のショートカットと同じ)。クリックで展開、✎ で「開く/名前を変更/削除」(削除は中身ごと消えるのでページ削除と同じくもう一段確認)
  - `openFolderView()/renderFolderView()/closeFolderView()`: body直下のオーバーレイ。**開いているフォルダはIDで保持**し、`onBookmarksState` → `loadShortcuts()` のたびに中身を描き直す(パネル側で足した/消したものが即反映される。フォルダ自体が消えたら閉じる)。ページ切り替え時も閉じる
  - `--cell`(アイコンサイズ)は `#quick-links` に載るのでbody直下のオーバーレイには継承されない。`applyGridMetrics()` と `renderFolderView()` の両方で `.folder-view` にも同じ値を書く
  - Escapeは上に開いているもの(編集モーダル・アイコンピッカー・ポップアップ)があるときは無視。`swipeExcluded` と右クリックの追加メニュー除外にも `.folder-view-backdrop` を追加
  - ページ名の改名(`beginPageRename`)とフォルダ名の改名を `beginInlineRename()` に統一
- `newtab.css`: `.tile.group-tile`(2x2のミニタイル)、`.folder-view-backdrop`(z-index 55=編集モーダル60・ポップアップ80より下、背景ぼかし)、`.folder-view`
- **開くアニメーションで `opacity` を動かさない**(拡大だけ)。描画が進まない状況ではアニメーションが開始キーフレームのまま止まり、**透明のまま=開いていないように見える**(ページ切り替えで踏んだのと同じ罠)。実際に検証中に踏んだので、検証にも「開いたフォルダのopacityが1」を入れてある
- 検証: `scripts/test-newtab-widgets.js` に13項目追加(全90項目OK)。タイル表示・ミニアイコン4個まで・展開・入れ子フォルダを出さない・中身がaタグ・`--cell` の追従・Escape・空フォルダ・開いたまま中身が増えたら反映・フォルダ削除で自動的に閉じる、まで見る。**見た目の確認用に第1引数でスクショモード**(検証はせずフォルダの展開表示とタイルだけ撮って終わる)を追加。非表示ウィンドウは合成が進まず前のフレームが写るので実表示で起動し、`capturePage` は起動直後 UnknownVizError になるためリトライする。**2枚目以降も前のフレームが写ることがあるので、見せたい絵から先に撮る**

**やらなかったこと**: スタート画面からのフォルダ新規作成(作成はブックマークのパネル側のまま)と、アイコン同士を重ねてフォルダを作る操作(現在のドラッグは同じ大きさ同士を入れ替える仕様なので、変えると既存の並べ替えとぶつかる)。
