# 2026-08-01: 「既定のアプリの選択肢に表示されない」の原因は InstallInfo(ユーザー報告)

## 決定事項とWhy

上の対応をしてもなお、設定アプリの「既定のアプリ」にRoopieが出てこないという報告。原因は**2つ重なっていた**。

### 原因1: そもそもリリースされていなかった

`default-browser-registry.js` を足した2コミット(`6001e97` / `e743899`)が**未push**で、インストール済みの0.1.38(= `ce6186e` のビルド)には登録コードが入っていなかった。裏付け:

- `git log -- src/main/default-browser-registry.js` の結果が未pushの2件だけ
- インストール済みの `%APPDATA%\Roopie\default-browser-state.json` に `registeredStamp` のキーが無い(= `ensureRegistered` を持たない世代の `DEFAULT_STATE`)

masterへのpushは即リリース(GitHub Actions → Releases → 自動更新)なので、**pushする前に登録内容が本当に正しいかを確かめた**。ビルドせずに確かめる手順:

1. `register()` と同じentriesを、`exe` だけインストール済みの `%LOCALAPPDATA%\Programs\Roopie\Roopie.exe` に差し替えて `reg.exe` で手書きする(**`electron.exe` では絶対にやらない**。開発中のelectronがブラウザとして居座る)
2. `SystemSettings` プロセスを落としてから `ms-settings:defaultapps` を開き直す(常駐しているので開き直さないと古いまま)
3. 判定は**設定アプリで実際に見る**しかない。`HKCU\Software\Microsoft\Windows\CurrentVersion\ApplicationAssociationToasts` に `VivaldiHTM.…_http` のようなエントリがあるのを見て「登録が効いた目印になるのでは」と考えたが、**使えない**——Roopieは一覧に出るようになった後も、直行リンクが着地した後も**ずっと空のまま**だった。あれは「そのアプリが既定に選ばれたことがある」履歴であって、登録の可否とは関係ない

### 原因2: `InstallInfo` が無いと Capabilities まで書いても一覧に出ない

上の手順で試したところ、`Capabilities` / `RegisteredApplications` を正しく書いても**一覧に出ず**、`ApplicationAssociationToasts` にも何も生えなかった。HKCUのVivaldiの登録をダンプして比べた結果、構造上の差は `Software\Clients\StartMenuInternet\<name>\InstallInfo` **1つだけ**だった:

| | Roopie(修正前) | Vivaldi |
|---|---|---|
| `Capabilities`(Name/Icon/Description/StartMenu/URLAssociations/FileAssociations) | あり | あり |
| `DefaultIcon` / `shell\open\command` | あり | あり |
| `Software\Classes\<ProgId>`(+`Application`/`DefaultIcon`/`shell\open\command`) | あり | あり |
| **`InstallInfo`** | **なし** | **あり** |

`InstallInfo`(`ReinstallCommand` / `HideIconsCommand` / `ShowIconsCommand` / `IconsVisible`)を足した瞬間に**設定アプリの検索で「Roopie」が出るようになった**(ユーザー確認済み)。中身はSPAD(Set Program Access and Defaults)時代の名残でRoopie自身は解釈しないが、**キーが無いとWindowsはそのクライアントを「ブラウザ」として数えない**。Chrome/Edge/Vivaldiはいずれも書いている。`IconsVisible` だけ `REG_DWORD` なので、`regAdd()` に型の引数を足した。

- `build/installer.nsh` は**変更不要**。`DeleteRegKey HKCU "Software\Clients\StartMenuInternet\Roopie"` は再帰なので `InstallInfo` も一緒に消える(検証スクリプトの `cleanupRegistration()` も同じ)
- `Startmenu` と `StartMenu` の表記ゆれ(Vivaldiは小文字m)は無関係。レジストリのキー名は大文字小文字を区別しない
- 検証に「`InstallInfoを書く`」を追加(`npx electron scripts/test-default-browser.js` 全項目パス)
