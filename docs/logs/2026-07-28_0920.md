# 2026-07-28: スタート画面からフォルダを作成 + フォルダのカスタムアイコン

## 決定事項とWhy

ユーザー依頼2件「スタート画面の右クリックメニューからフォルダを作成できるようにして」「フォルダにもカスタムアイコンを設定できるようにして」。

- メイン側
  - `bookmarks.js` `addFolder(parentId, title, icon)` … 作成時にアイコンを持てる(`normalizeIcon` を通すのでショートカットと同じ検証。既定は null)
  - `bookmarks.js` `updateItem()` … アイコンの反映を `type === 'bookmark'` の中から外に出し、**フォルダにも効く**ようにした(URL/種別の扱いはブックマークのときだけ、は据え置き)
  - `ipc.js` `bookmarks:add-folder` を `on` → **`handle`** に変更(作ったフォルダを返す。`bookmarks:add-shortcut`/`start-page-add` と同じ流儀)。`internal-preload.js` の `addBookmarkFolder` も invoke に。サイドパネル側の呼び出しは戻り値を見ていないのでそのまま動く
- レンダラー(`newtab.js`)
  - 右クリックの追加メニューに「📁 フォルダ」を追加 → `openFolderModal(null)`
  - `openFolderModal(existing)` … 名前+アイコン(共通の `icon-picker.js`)だけの小さいモーダル。ショートカットの追加モーダルと同じ見た目。フォルダの ✎ メニューは「開く / 名前・アイコンを変更 / 削除(確認あり)」の3項目に整理(その場改名は展開表示のタイトルのダブルクリックに集約)
  - `tileIconContent()` に**フォルダの分岐**を入れた。カスタムアイコンがあればそれを描き、無ければ中身を2x2で並べたプレビュー。`group-tile` クラスの付け外しもここで行うので、カスタムアイコンのときは普通のタイルと同じ見せ方になる(`groupTileEl` は不要になり削除、`shortcutTileEl` に統合)
- 検証: `scripts/test-newtab-widgets.js` に11項目追加(追加メニュー6項目・追加モーダル・作成・✎からの編集・アイコンピッカーで絵文字を選ぶ・タイルがカスタムアイコンになる・そのとき2x2をやめる・それでもフォルダとして開ける)、`scripts/test-bookmarks-manager.js` に6項目追加(作成時のアイコン・不正なアイコンの弾き方・後からの変更・既定に戻す)。スタブ `stub-internal-preload.js` に `addBookmarkFolder` を実装し、`updateShortcut` をページだけでなくページ内アイテムの名前・アイコンにも効くようにした

**やらなかったこと**: ブックマークのパネル/管理画面のフォルダ行は今までどおり `📁` のまま(カスタムアイコンはスタート画面のタイルにだけ効く)。
