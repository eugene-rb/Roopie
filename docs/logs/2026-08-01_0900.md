# 2026-08-01: 既定のブラウザへの設定を簡単にした(ユーザー依頼)

## 決定事項とWhy

依頼は「既定のブラウザに設定するのを簡単にして」。調べたところ、簡単以前に**2つ壊れていた**。

### 壊れていたこと

1. **設定アプリの一覧にRoopieが出てこない**。従来は `app.setAsDefaultProtocolClient('http'/'https')` + `ms-settings:defaultapps`(一覧)を開くだけだった。ElectronのこのAPIは `HKCU\Software\Classes\http\shell\open\command` を書くだけで、Windowsが「既定のアプリ」に並べるための `RegisteredApplications` / `StartMenuInternet` には**何も書かない**。つまりユーザーは一覧を開かれても選ぶ相手が居ない。
2. **既定にできても他アプリのリンクが開かない**。`main.js` の `second-instance` が `argv` を捨てて既存ウィンドウをフォーカスするだけだった。起動時の `process.argv` も見ていない。既定のブラウザは `"Roopie.exe" "%1"` で呼ばれるので、これでは「Roopieが前に出るだけで何も起きない」。

### やったこと

- `src/main/url-args.js`(新規): argvから開くURLを1つ取り出す。`http`/`https` と**実在する** `.htm/.html`(→ `pathToFileURL`)だけを受け付け、`javascript:` や `roopie://` は無視する(外部から内部ページ・スクリプトを叩かれないため)。`-` 始まりはChromium/Electronのスイッチなので飛ばす。
- `main.js`: 起動時(`process.argv`)と `second-instance` の両方で使う。**`appState.takeStartupUrl()` は消費してしまう**ので、外部URLがあってもイントロ/変更点を捨てない(`openStartupWindows({ url, externalUrl })` で両方開く)。
- `browser.openExternalUrl()`: フォーカス中の**非シークレット**ウィンドウ(無ければ最初の通常ウィンドウ、それも無ければ新規)の**末尾**にタブを足す。リンククリック相当なので `nearActive` は付けない(CLAUDE.mdの方針)。
- `src/main/default-browser-registry.js`(新規): Chrome/Edgeと同じ形の登録を `reg.exe`(execFile。シェルを介さないので日本語も化けない)でHKCUへ書く。
  - `Software\Classes\RoopieHTML`(+`DefaultIcon` / `shell\open\command` = `"exe" "%1"` / `Application`)
  - `Software\Clients\StartMenuInternet\Roopie`(+`DefaultIcon` / `shell\open\command` / `Capabilities`: ApplicationName・URLAssociations(http/https)・FileAssociations(.htm/.html)・StartMenu)
  - `Software\RegisteredApplications\Roopie` → 上のCapabilitiesのパス
  - **`app.isPackaged` のときだけ**書く(開発中はexeが `electron.exe` なので、登録すると他プロジェクトでも居座る)。書き直すのは実行ファイルの場所かバージョンが変わったときだけ(`default-browser-state.json` の `registeredStamp`)。
- `default-browser.js`: 登録できていれば `ms-settings:defaultapps?registeredAppUser=Roopie` で**Roopieのページへ直行**(Windows 11なら「既定に設定する」1クリックで http/https/.htm/.html がまとめて切り替わる)。できていなければ従来どおり一覧へフォールバック。押した後は `app.on('browser-window-focus')` で `isDefault()` を確かめ(反映が遅れるので1.5秒後にもう一度)、切り替わっていたら各ウィンドウへ `default-browser:state` を配る。
- お願いバー(`renderer.js`): 押しても**閉じない**。「Windowsの設定が開きます。「既定に設定する」を押すと切り替わります」に変わり、既定になったら「Roopieが既定のブラウザになりました」を出して3秒で自動的に閉じる。
- 設定画面「ブラウザ設定」の先頭に**既定のブラウザ**の行を追加(状態表示+ボタン、既定なら「設定済み」で押せない)。バーは2回見送ると2週間出ないので、恒久的な導線はこちら。押した後に設定アプリから戻ってフォーカスで再確認したとき、まだ既定でなければ**手順を出したまま**にする(`defaultBrowserAsked`)。
- `build/installer.nsh`: アンインストール時に登録を消す。**`${ifNot} ${isUpdated}` の中に入れるのが必須**——electron-updaterは自動更新のたびにアンインストーラーを走らせるので、無条件に消すと更新のたびにRoopieが既定から外れる。

### レビューで見つけた偽陽性(重要)

`isDefault()` を `app.isDefaultProtocolClient()` のままにしていたら、**押しただけで「設定済み」になる**ところだった。実測(`Classes\http` を消して確認):

| `HKCU\Software\Classes\http\shell\open\command` | UserChoice(実際の既定) | `isDefaultProtocolClient('http')` |
|---|---|---|
| `electron.exe` | `MSEdgeHTM` | **true** |
| (キーなし) | `MSEdgeHTM` | false |

つまりElectronのAPIは `Classes\http` のコマンドしか見ておらず、**`setAsDefaultProtocolClient()` を呼んだ自分自身をtrueと答える**。これでは設定アプリを閉じただけのユーザーに「Roopieが既定のブラウザになりました」と出て、設定画面のボタンも「設定済み」で押せなくなり、**やり直す導線がないのにリンクはEdgeで開く**という最悪の状態になる。

直し方: 判定を `HKCU\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\<http|https>\UserChoice` の `ProgId === 'RoopieHTML'` に変えた(`reg.exe` を `execFileSync`。`shouldPrompt()` が同期なのでキャッシュし、起動時・フォーカス時・設定画面を開いたときに `refresh()`)。あわせて**Windowsでは `setAsDefaultProtocolClient` を呼ぶのをやめた**(Capabilities登録で足りる。あれは偽陽性の原因そのもので、開発マシンに `Classes\http` のゴミも残す)。非Windowsでは従来どおり。

### 検証(`npx electron scripts/test-default-browser.js`)

既存の検証スクリプトに追加した(全項目パス)。途中でハマった点:

- 回帰ガードとして「押しただけでは既定と判定しない」「登録しただけでは既定にならない」を入れた(上の偽陽性はスタブが隠してしまうため、`refresh()` の戻り値を直接見る)。
- **本物の `app.setAsDefaultProtocolClient` を1度でも呼ぶと、検証用の `electron.exe` が `HKCU\Software\Classes\http` のハンドラとして登録されてしまう**(実際に汚してから気付き、`reg delete` で掃除した。UserChoiceは触らないので実際の既定ブラウザは無傷)。スタブは**テストの最後まで戻さない**こと。
- レジストリ登録そのものは `app.isPackaged` を一時的に `true` に見せかけて**本当に書き**、キーの中身を `reg query` で確かめてから `finally` で必ず消す(消えたことも検証項目にしてある)。
- 背面ウィンドウの `setTimeout` はChromiumに間引かれるので、3秒の自動クローズは6秒待って確かめる。`Store` の保存は300msデバウンスなので、JSONは期待の内容になるまで待って読む。
- タブのURL確認は `tab.url` ではなく `snapshotTabs()`。読み込みが commit されないと `getURL()` は空なので、検証には通信の要らないローカルHTMLを使う。

### 未確認だった点 → 確認済み(2026-08-01(2))

`ms-settings:defaultapps?registeredAppUser=Roopie` は実機でRoopieの個別ページ(「既定に設定する」ボタンのある画面)に**着地する**。ただし登録が効いていること(下の `InstallInfo` )が前提で、一覧に出ない状態では一覧のまま開く。
